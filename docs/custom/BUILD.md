# Сборка и установка

## Текущее состояние

Используется внешний локальный скрипт zcode-build.
Он проверяет Contracts и TUI, сохраняет резервную
копию артефактов, собирает CLI и перезапускает сервис.

## Известные ограничения

- Нет полного набора CLI-проверок.
- Shared не включён в резервное копирование.
- Сборка выполняется в рабочем каталоге.
- Нет подтверждённой проверки активности агента.
- HEAD исходников не обязательно соответствует
  установленной версии.
- Сборка и установка не разделены.

## Целевая архитектура

Сборка выполняется в отдельном каталоге.
Каждый кандидат связан с точным Git SHA.
Установленная версия не изменяется при тестировании.

Планируемые команды:

- zcode-status
- zcode-check-update
- zcode-update
- zcode-test
- zcode-build
- zcode-deploy
- zcode-rollback

Эти команды, кроме существующего zcode-build,
пока являются проектируемыми интерфейсами.

## Проверки

Официальные команды и package.json являются
источником истины.

Включать:

- Root typecheck и lint.
- Architecture check.
- Shared build.
- Contracts typecheck и tests.
- TUI typecheck и tests.
- CLI typecheck и tests.
- CLI version/help smoke tests.
- Целевые регрессионные проверки.

Для подготовки зависимостей изучить официальный
build:sea:prepare без обязательной упаковки SEA.

Установка допускается только после подтверждения
отсутствия активной задачи и наличия рабочего отката.

Локальные конфигурации, ключи, журналы и данные
пользователей не публикуются в репозитории.
