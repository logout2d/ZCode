# ZCode Custom

Собственный форк официального ZCode.

## Цели

- Исправление ошибок CLI и TUI.
- Корректная работа с внешними AI-провайдерами.
- Надёжное управление контекстом и сессиями.
- Локальная сборка и тестирование.
- Регулярная интеграция официальных обновлений.
- Минимизация отличий от upstream.
